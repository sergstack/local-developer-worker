# Local Developer Utility Layer для Codex

Local Developer Utility Layer — это локальный сервисный слой, который помогает Codex быстрее и точнее выполнять задачи разработки. Он извлекает проверяемые факты из репозитория, логов, результатов тестов и Git-состояния, структурирует их в компактный контекст и передаёт Codex только релевантную информацию для анализа, исправления кода и проверки результата.

Проект не заменяет Codex и не создаёт автономного локального агента. Архитектурные решения, сложный debugging, изменения кода, проверка и финальные выводы остаются за Codex. Локальные инструменты берут на себя узкие, контролируемые операции: разбор больших логов, фиксацию фактических статусов тестов, сбор изменений, инвентаризацию файлов и подготовку evidence-linked пакетов контекста.

Ключевой принцип проекта — разделение ответственности. Детерминированные компоненты работают только с наблюдаемыми фактами и могут использоваться автоматически. Локальные модельные помощники применяются лишь для ограниченных задач — классификации, группировки повторяющихся ошибок, кратких summaries и подготовки документации — а их результаты всегда имеют статус `candidate` и требуют проверки Codex.

Решение развивается поэтапно. В первую очередь создаётся deterministic core: structured log parser, test result parser, Git and change facts collector и file inventory. Затем добавляются context packer и evidence package, которые уменьшают объём передаваемого контекста и упрощают продолжение задач между сессиями. Только после подтверждения эффекта подключаются локальная семантическая помощь, генерация отчётов и ограниченных кодовых артефактов. Автоматический выбор инструментов допускается лишь после supervised-пилотов и измеримой пользы.

Ожидаемый результат для пользователя — меньше ручной работы с логами и файлами, более достоверные статусы тестов, компактные доказательные отчёты и более предсказуемая работа Codex. Все решения оцениваются по фактической телеметрии: сокращению контекста, времени выполнения, числу отклонённых результатов, fallback-сценариям и чистой экономии ресурсов.

Проект сознательно исключает автоматическое редактирование кода, коммиты, merge, деплой, самостоятельные архитектурные решения и утверждение root cause без доказательств. Это позволяет получить практическую пользу от локальных инструментов, сохранив безопасность, прозрачность и контроль над разработкой.
